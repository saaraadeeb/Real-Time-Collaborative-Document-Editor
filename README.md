# REAL-TIME COLLABORATIVE DOCUMENT EDITOR

*DOMAIN*: FULL STACK WEB DEVELOPMENT

*MENTOR*: NEELA SANTHOSH

 The Real-Time Collaborative Document Editor is a web-based application developed using Full Stack Development technologies. The main objective of this project is to allow multiple users to edit and view the same document simultaneously in real time. This project demonstrates the practical implementation of frontend development, backend development, and real-time communication between users.
For the frontend development, React.js was used to create an interactive and user-friendly interface. React.js helps in building dynamic web applications by updating the user interface efficiently whenever changes occur. The editor page contains a text area where users can enter and edit content. The design is simple and easy to use, making the application accessible for all users.
For the backend development, Node.js and Express.js were used. Node.js provides a JavaScript runtime environment that allows server-side programming, while Express.js simplifies the process of creating web servers and handling requests. The backend server is responsible for managing user connections and transmitting data between different users connected to the application.
Socket.io was used to implement real-time communication. Socket.io enables instant data transfer between the client and server without requiring page refreshes. Whenever a user types any text in the editor, the changes are immediately sent to the server through Socket.io. The server then broadcasts the updated content to all connected users. As a result, every user can view the latest document changes in real time. This functionality is similar to popular collaborative platforms such as Google Docs.
During the development process, a React application was created using Create React App. Required packages such as socket.io-client were installed for frontend communication. On the server side, Express.js, Socket.io, and CORS packages were installed and configured. The server was set up to listen on port 5000, while the React application was executed on a local development port. Proper communication between the frontend and backend was established using Socket.io events.
The application was tested by opening multiple browser tabs. When text was entered in one tab, the same content appeared instantly in the other tab without refreshing the page. This confirmed that the real-time synchronization feature was functioning correctly. The project successfully demonstrated how multiple users can collaborate on a shared document through a web application.
This project provided valuable experience in Full Stack Development by integrating frontend technologies, backend services, and real-time communication mechanisms. It improved understanding of React.js components, state management, Node.js server creation, Express.js routing, and Socket.io event handling. The project also highlighted the importance of client-server architecture in modern web applications.

The terminal confirms that the server is running successfully on port 5000 and users are connected to the application through Socket.io for real-time communication.
